This project is part of a Master's Thesis in Applied Data Science in Utrecht University. This study is aimed at the automatic evaluation of curriculum alignment. Specifically, it investigates both generative (GPT-4.1 nano) and non-generative (mBERT) models using a labeled dataset of Dutch statistics questions.

*The "ADS_thesis_project_IsabelaMotoki" refers to the report. 

*Dataset used was downloaded from https://www.sharestats.nl/ (code used for downloading can be found in src folder "Downloading Dataset.R").

*Code used in python is found on src "Thesis_FinalCode_Git.ipynb"
